# CommonScope Workbench

## Objective
Build the unified frontend workbench for CommonScope.

## Scope
- Show tools from the Registry
- Show routing results
- Show blackboard state
- Make the system flow understandable

## Suggested stack
- React
- TypeScript
- Vite
- Component library
- React Flow or D3

## Expected deliverables
- Integrated frontend
- Pages for Registry, Router, and Blackboard
- Demo-ready UI
- Documentation
