# CommonScope Blackboard

## Objective
Build the shared session, evidence, and messaging space for CommonScope.

## Scope
- Create work sessions
- Save blackboard entries
- Support filtering and retrieval
- Track consensus and conflict

## Suggested stack
- FastAPI
- PostgreSQL
- Redis (optional)
- WebSocket (optional)

## Expected deliverables
- Blackboard data model
- API
- Session demo
- Minimal tests
- Documentation
